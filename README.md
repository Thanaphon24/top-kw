# top-kw — ติวสอบ กว. ภาคีวิศวกร สาขาอุตสาหการ

เว็บฝึกทำข้อสอบทดสอบความรู้ระดับภาคีวิศวกร สาขาวิศวกรรมอุตสาหการ (แยกจากเว็บ top-toeic)

- **สอบเสมือนจริง**: หมวดวิชาพื้นฐาน และหมวดวิชาเฉพาะ หมวดละ 4 วิชา วิชาละ 25 ข้อ รวม 100 ข้อ 3 ชั่วโมง เกณฑ์ผ่านร้อยละ 60
- **ฝึกรายวิชา**: เลือกวิชาและหัวข้อ ดูเฉลยพร้อมคำอธิบายทันที
- ข้อสอบและเฉลยอ้างอิงคลังข้อสอบที่สภาวิศวกรเผยแพร่ (4,984 ข้อ 12 วิชา)

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเว็บทั้งหมด |
| `data.js` | รายการข้อสอบ: หัวข้อ เฉลย จำนวนตัวเลือก |
| `img/<วิชา>/<เลขข้อ>.webp` | ภาพโจทย์และตัวเลือกของแต่ละข้อ |
| `expl.js` | คำอธิบายเฉลย `KW_EXPL[วิชา][เลขข้อ]` |
| `config.json` | เปิด/ปิดเว็บ: ตั้ง `"open": false` เพื่อปิด และใส่ข้อความใน `"message"` |
